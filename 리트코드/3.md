# Longest Substring Without Repeating Characters

## 분석

- 주어진 문자열에서 반복되는 문자가 없는 substring의 최대 길이를 구해서 리턴한다.
- 문자열은 영어 글자, 숫자, 기호, ' '로 이루어져 있다.
- 0 <= s.length <= 50000

## 풀이 

- visited 배열로 중복 체크를 했다. 인덱스에 들어가는 문자가 substring에 포함되면 해당 인덱스 위치의 값을 true로 바꿔준다.
- 문자열이 기호나 space까지 포함하고 있기 때문에 아스키코드의 범위를 모두 포함할 수 있도록 visited 배열의 길이를 200으로 잡았다.
- substring은 s 문자열의 순서를 그대로 유지해야 하기 때문에 슬라이딩 윈도우를 사용했다.
- 새로 추가한 j가 이미 사용된 문자인 경우, j를 사용하지 않는 곳까지 i를 오른쪽으로 옮겨서 새로 문자열의 길이를 확인하도록 했다.
- substring은 i에서 j까지의 문자열이기 때문에 길이가 j-i+1 이다.

```java

class Solution {
    public int lengthOfLongestSubstring(String s) {
        
        boolean[] visited=new boolean[200];
        int max=0;
        int i=0;
        int j=0;

        while(i<=j && j<s.length()){
            int end=(int)s.charAt(j);
            
            while(visited[end]){                
                int start=(int) s.charAt(i);
                visited[start]=false;
                i++;
            }

            visited[end]=true;
            max=Math.max(max,j-i+1);
            j++;
        }

        return max;
    }
}

```
