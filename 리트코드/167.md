# Two Sum II - Input Array Is Sorted

## 분석

- 배열 numbers는 오름차순이다.
- numbers[i]+numbers[j]=target이 되는 i와 j를 리턴한다. 이 때 i와 j는 같은 값이 될 수 없다.
- -1000 <= numbers[i] <= 1000 이기 때문에 단순히 target보다 큰 수가 포함될 수도 있다.

## 풀이

- 인덱스 0부터 체크하는 small, 가장 마지막 인덱스부터 체크하는 big 을 두고 두 수의 합과 target을 비교해서 값을 조정한다.
- target이 합보다 큰 경우: big을 1만큼 감소시킨다.
- target이 합보다 작은 경우: small을 1만큼 증가시킨다.
- target과 합이 같은 경우: 탐색을 종료한다.

```java

class Solution {
    public int[] twoSum(int[] numbers, int target) {
        
        int small=0;
        int big=numbers.length-1;
        
        while(small<big){
            if(numbers[small]+numbers[big]>target){
                big--;
            }
            else if(numbers[small]+numbers[big]<target){
                small++;
            }
            else {
                break;
            }
        }

        int[] ans=new int[2];
        ans[0]=small+1;
        ans[1]=big+1;

        return ans;
    }
}

```
