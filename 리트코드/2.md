# Add Two Numbers

## 분석

- 2개의 양수로 이루어진 LinkedList가 있다. 숫자들은 역순으로 저장되어 있고, 각 노드는 하나의 숫자를 가지고 있다.
- 두 수를 더해서 LinkedList 형식으로 합을 리턴한다.
- 예시처럼 한 노드에서 합이 10 이상이 되면 다음 노드로 올림 처리된다.
  ```bash
  Input: l1 = [2,4,3], l2 = [5,6,4]
  Output: [7,0,8]
  Explanation: 342 + 465 = 807.
  ```

## 풀이

- up: 앞의 연산에서 올림 처리된 숫자. 시작할 때에는 올림 처리된 숫자가 없기 때문에 0으로 시작한다.
- ans: 합 연산의 결과 ListNode. 단방향 LinkedList이기 때문에 next값을 갱신해주기 위하여 -1로 시작한다. 연산 마지막에 ans.next로 리턴한다.
- l1과 l2의 길이가 다를 수 있고, l1과 l2의 합을 다 체크했더라도 앞의 연산에서 올림수가 있을 수도 있기 때문에 `while(l1!=null || l2!=null || up!=0)` 동안 합 연산을 진행한다.

```java

/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        ListNode ans=new ListNode(-1);
        ListNode pos=ans;
        int up=0;

        while(l1!=null || l2!=null || up!=0){
            int val=up;
            
            if(l1!=null){
                val+=l1.val;
                l1=l1.next;
            }

            if(l2!=null){
                val+=l2.val;
                l2=l2.next;
            }

            up=val/10;
            val=val%10;
            pos.next=new ListNode(val);
            pos=pos.next;
        }
        return ans.next;
    }
}

```
