# Isomorphic Strings

## 분석

- 두 문자열 s, t가 주어졌을 때 s의 문자가 t의 문자로 대응될 수 있으면 isomorphic 하다고 한다.
- 두 문자열의 isomorphic 여부를 리턴한다.

## 풀이

- isomorphic하기 위해서는 대응되는 문자의 순서가 유지되어야 한다.
- 인덱스 0부터 문자가 차례대로 대응된다고 가정하고 map에 key-value 값으로 넣는다. 
- s를 map에 저장된 문자로 변환한다.
- 변환한 결과가 t와 일치한다면 true를, 일치하지 않는다면 false를 리턴한다.
- 해시맵은 key에 대해서만 중복을 체크하기 때문에 t에 대한 중복 체크를 위해 set을 추가했다.

```java

class Solution {
    public boolean isIsomorphic(String s, String t) {
        Map<Character, Character> map=new HashMap<>();
        Set<Character> set=new HashSet();

        for(int i=0;i<s.length();i++){
            if(map.get(s.charAt(i))!=null) continue;
            if(set.contains(t.charAt(i))) continue;
            map.put(s.charAt(i), t.charAt(i));
            set.add(t.charAt(i));            
        }

        StringBuilder sb=new StringBuilder();
        
        for(int i=0;i<s.length();i++){
            sb.append(map.get(s.charAt(i)));
        }

        System.out.println(sb.toString());

        if(sb.toString().equals(t)){
            return true;
        }

        return false;
    }
}

```
