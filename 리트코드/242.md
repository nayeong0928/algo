# Valid Anagram

## 분석

- 문자열 s와 t가 anagram인지 여부를 리턴한다.
- anagram: 다른 단어의 철자를 한번씩만 사용해서 재배열해서 만든 단어.


## 풀이

- s의 각 철자가 몇번씩 들어 있는지 세어주면서 map에 저장한다.
- t의 각 철자가 몇번씩 들어 있는지 세어주면서 map에 1씩 감소시킨다.
- map에 0이 아닌 철자가 있는 경우 false를 리턴하고, 모든 철자가 0인 경우는 true를 리턴한다.

```java

class Solution {
    public boolean isAnagram(String s, String t) {
        Map<Character, Integer> map=new HashMap<>();
        
        for(int i=0;i<s.length();i++){
            char ch=s.charAt(i);
            map.put(ch, map.getOrDefault(ch,0)+1);            
        }

        for(int i=0;i<t.length();i++){
            char ch=t.charAt(i);
            map.put(ch, map.getOrDefault(ch, 0)-1);
        }

        for(Map.Entry<Character, Integer> entry: map.entrySet()){
            if(entry.getValue()!=0){
                return false;
            }
        }

        return true;
    }
}

```
