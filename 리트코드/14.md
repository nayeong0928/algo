# Longest Common Prefix

## 분석

- String 문자열 배열이 주어질 때, 가장 긴 Common Prefix를 리턴
- Common Prefix가 없는 경우, ""를 리턴
- 1 <= strs.length <= 200
- 0 <= strs[i].length <= 200
- strs[i] 는 비어있지 않은 경우 영어 소문자로 이루어져 있다

## 풀이

- String.substring(i, j) 는 문자열 i ~ (j-1) 을 리턴하기 때문에 for문으로 인덱스를 셀 경우, 문자열 길이 이내까지만 인덱스가 증가하기 때문에 while문으로 변경해주었다.

```java

class Solution {
    public String longestCommonPrefix(String[] strs) {
        
        int i=0;

        while(true){
            
            if(i>=strs[0].length()){
                break;
            }

            if(!common(strs,i)){
                break;
            }

            i++;   
        }
        
        return strs[0].substring(0, i);
    }

    private static boolean common(String[] strs, int idx){

        char ch=strs[0].charAt(idx);

        for(int i=0;i<strs.length;i++){
            // System.out.println("i: "+i);
            if(idx>=strs[i].length() || ch!=strs[i].charAt(idx)){
                return false;
            }
        }

        return true;
    }
}

```
