# Word Pattern

## 분석

- s의 단어가 pattern의 문자들과 같은 패턴을 갖는지 여부를 리턴하는 문제이다.
- 같은 패턴을 갖는다는 것은 다음 조건을 의미한다.
  - pattern의 문자는 s의 정확히 하나의 단어와 대응된다.
  - s의 각 고유 단어는 pattern의 정확히 하나의 문자와 대응된다.
  - 두 단어가 같은 문자에 매핑되지 않고, 두 문자가 같은 단어에 매핑되지 않는다.

## 풀이

- hash: pattern의 문자와 s의 단어를 매핑한다.
- set: HashMap은 key의 중복 체크만 하기 때문에 s의 중복 체크를 위해 HashSet을 사용했다.

```java

class Solution {
    public boolean wordPattern(String pattern, String s) {
        Map<Character, String> hash=new HashMap<>();
        Set<String> set=new HashSet<>();
        String[] str=s.split(" ");

        if(pattern.length() != str.length) {
            return false;
        }

        for(int i=0;i<pattern.length();i++){
            char ch=pattern.charAt(i);

            if(hash.get(ch)==null && !set.contains(str[i])){
                hash.put(ch, str[i]);
                set.add(str[i]);
            }
        }

        for(int i=0;i<pattern.length();i++){
            char ch=pattern.charAt(i);

            if(hash.get(ch)==null || !hash.get(ch).equals(str[i])){
                return false;
            }
        }

        return true;
    }
}

```
