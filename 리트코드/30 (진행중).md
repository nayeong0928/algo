# Substring with Concatenation of All Words

## 분석

- 문자열 배열 words는 모두 같은 길이이다.
- concatenated string : words의 순열로 이루어진 문자열. words를 한번씩 모두 포함해야 하며 순서는 상관 없다.
- concatenated string 의 시작 인덱스 리스트를 리턴한다. 이 때, 순서는 상관 없다.

## 풀이

- start : 현재 체크하고 있는 문자열의 시작 인덱스.
- i : 단어와 비교할 문자열 부분. i ~ i+N 까지의 부분 문자열이 words에 있는 단어와 일치하는지 확인한다.
- wordList : 중복 체크를 쉽게 하기 위해 words에 있는 단어들을 HashSet으로 저장함.
- count : HashMap으로 start에서부터 i+N 까지의 문자열이 포함하는 단어들의 개수를 저장한다. 

### condition()

1. word를 전부 하나씩 가지고 있는 경우 : start를 list에 추가하고 start를 문자열 길이 N만큼 증가시킨다.
2. word 중에서 0개인 것이 존재하는 경우 : 계속 확인이 필요한 상태.
3. word 중에서 2개 이상인 것이 존재하는 경우 : start를 문자열 길이 N만큼 증가시킨다.

### 전체 코드 - 수정중

```java

class Solution {

    static Map<String, Integer> count;
    static Set<String> wordList;
    static int i, start, N;
    
    static final int CONCATENATED=0;
    static final int COUNTING=1;
    static final int NOT_CONCATENATED=2;
    
    public List<Integer> findSubstring(String s, String[] words) {
        count=new HashMap<>();
        wordList=new HashSet<>();
        i=0;
        start=0;
        N=words[0].length();
        List<Integer> list=new ArrayList<>();

        for(String w: words){
            wordList.add(w);
            count.put(w, 0);
        }
        
        while(i+N<s.length()){
            switch(condition(s)){
                case CONCATENATED:
                    addList(s, list);
                    break;
                case COUNTING:
                    add(s.substring(i, i+N));
                    break;
                case NOT_CONCATENATED:
                    del(s);
                    break;                    
            }
        }

        return list;
    }

    private static int condition(String s){

        if(!wordList.contains(s.substring(i, i+N))){
            return NOT_CONCATENATED;
        }
        
        for(Map.Entry<String, Integer> entry: count.entrySet()){
            if(entry.getValue()==0){
                return COUNTING;
            }
            if(entry.getValue()>=2){
                return NOT_CONCATENATED;
            }
        }

        return CONCATENATED;
    }

    private static void addList(String s, List<Integer> list){
        list.add(start);
        i+=N;
        
        while(start<i){
            if(wordList.contains(s.substring(start, start+N))){
                count.put(s.substring(start, start+N), count.getOrDefault(s.substring(start, start+N), 0)-1);
            }
            start+=N;
        }
        
    }

    private static void add(String str){
        count.put(str, count.getOrDefault(str, 0)+1);
        i+=N;
    }

    private static void del(String s){
        i+=N;
        
        while(start<i){
            if(wordList.contains(s.substring(start, start+N))){
                count.put(s.substring(start, start+N), count.getOrDefault(s.substring(start, start+N), 0)-1);
            }
            start+=N;
        }
    }    
}

```
