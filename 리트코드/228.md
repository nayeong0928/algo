# Summary Range

## 분석

- range [a,b] : a에서 b까지의 모든 정수를 포함하는 범위
- nums는 오름차순 배열

## 풀이

- start, end: 현재 체크 중인 range의 시작/끝 값
- nums 순회하면서 cnt와 값 비교
 - n이랑 같은 경우에는 range에 들어가는 값으로 묶고: end 값 갱신
 - n이랑 다른 경우에는 새로운 range 생성해서 거기에 넣기: list에 기존의 값을 저장하고 start, end, cnt 값 갱신


```java

class Solution {
    public List<String> summaryRanges(int[] nums) {
        List<String> list=new ArrayList<>();

        if(nums.length==0) {
            return list;
        }

        int start=nums[0];
        int cnt=nums[0];
        int end=nums[0];

        for(int i=1;i<nums.length;i++){
            cnt++;
            if(cnt==nums[i]){
                end=cnt;
            }
            else {
                list.add(range(start, end));
                start=nums[i];
                cnt=nums[i];
                end=nums[i];
            }
        }

        list.add(range(start, end));
        
        return list;
    }

    private static String range(int start, int end){
        if(start==end){
            return start+"";
        }

        return start+"->"+end;
    }
}

```
