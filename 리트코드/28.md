# Find the Index of the First Occurrence

## 분석

- haystack 문자열 안의 needle 문자열이 처음 들어간 인덱스를 리턴하는 문제.
- needle 문자열이 haystack 보다 길 수도 있다.

## 풀이

- needle 문자열이 haystack 보다 긴 경우, needle이 haystack에 포함될 수 없으므로 -1 리턴.
- haystack에 needle 첫번째 문자와 같은 글자가 있으면 check() 메소드로 확인 -> needle 문자열을 포함하지 않을 수 있으므로 아닌 경우 마저 탐색.
- check()에서 i+start 가 haystack 길이보다 커질 수도 있으므로 확인.

```java

class Solution {
    public int strStr(String haystack, String needle) {

        if(needle.length()>haystack.length()) return -1;
        
        for(int i=0;i<haystack.length();i++){
            if(haystack.charAt(i)==needle.charAt(0) 
                && check(haystack, needle, i)){
                return i;
            }
        }

        return -1;
    }

    private static boolean check(String haystack, String needle, int start){
        for(int i=0;i<needle.length();i++){
            if((i+start)>=haystack.length()
                || haystack.charAt(i+start)!=needle.charAt(i)){
                return false;
            }
        }
        return true;
    }
}

```
