# Integer to Roman

## 분석

|Symbol|	Value|
|---|---|
|I	|1|
|IV  |4|
|V	|5|
|IX  |9|
|X	|10|
|XL  |40|
|L	|50|
|XC  |90|
|C	|100|
|CD  |400|
|D	|500|
|CM  |900|
|M  |1000|

- Roman 수는 큰 수부터 앞에 온다

## 풀이

```java

class Solution {
    public String intToRoman(int num) {
        String[] symbol={"M","CM","D","CD","C","XC", "L", "XL", "X", "IX", "V", "IV", "I"};
        int[] value={1000, 900, 500, 400, 100, 90, 50, 40, 10, 9, 5, 4, 1};
        StringBuilder sb=new StringBuilder();

        for(int i=0;i<symbol.length;i++){
            int t=num/value[i];
            num%=value[i];
            for(int j=0;j<t;j++){
                sb.append(symbol[i]);
            }
        }

        return sb.toString();
    }

}

```
