# Minimum Size Subarray Sum

## 분석

- 전체합이 target보다 크거나 작은 subarray 중에서 가장 짧은 길이를 리턴한다.
- subarray 전체 배열 중에서 연속된 부분 배열을 의미하기 때문에 배열을 정렬할 수 없다.
- 1 <= target <= 10^9 
- 1 <= nums.length <= 10^5
- 1 <= nums[i] <= 10^4

## 풀이

- subarray의 범위를 start ~ end 까지로 둔다.
- end를 배열 길이만큼 탐색하면서 target보다 크거나 같은 경우에는
  - subarray의 길이를 체크해서 기존 cnt값보다 더 작으면 cnt에 저장한다.
  - 다른 경우의 subarray도 확인해봐야 하기 때문에 sum에서 start번째의 원소를 빼고, start를 1 더해줘서 다시 sum을 target보다 작게 만든다. 

```java

class Solution {
    public int minSubArrayLen(int target, int[] nums) {

        int start=0;
        int cnt=Integer.MAX_VALUE;
        int sum=0;

        for(int end=0;end<nums.length;end++){
            sum+=nums[end];

            while(sum>=target){
                cnt=Math.min(cnt, end-start+1);
                sum-=nums[start];
                start++;
            }
        }

        if(cnt==Integer.MAX_VALUE){
            return 0;
        }

        return cnt;
        
    }
}

```
