# Valid Palindrome

## 분석

- 대문자 -> 소문자
- 숫자/알파벳 아닌 문자는 모두 지움
- 앞에서부터 읽은 것과 뒤에서부터 읽은 것이 같은지 체크해서 true/false 리턴해주기

## 풀이

### filter()

- 그대로 리턴하는 경우: 소문자이거나 숫자인 경우.
- 대문자인 경우: 소문자로 변환해서 리턴.
- 다른 경우: 공백 리턴. (char은 ''으로 초기화할 수 없기 때문에)

```java

    private static char filter(char ch){
        if(ch>='a' && ch<='z'){
            return ch;
        }
        if(ch>='0' && ch<='9'){
            return ch;
        }
        if(ch>='A' && ch<='Z'){
            return (char)(ch-'A'+'a');
        }
        return ' ';
    }

```

### isPalindrome()

- s 문자열을 하나씩 filter()에 넣어서 변환한 다음, sb에 덧붙인다.
- filter() 에서 해당되지 않는 값은 ' '로 리턴했기 때문에 리턴값이 ' '인 문자는 sb에 덧붙이지 않는다.
- start: 왼쪽부터 s 문자열 체크하는 변수.
- end: 오른쪽부터 s 문자열 체크하는 변수.
- while문에서 start 위치의 문자와 end 위치의 문자가 다르면 return false.
- 리턴되지 않고 while문을 통과하면 return true.

```java

class Solution {
    public boolean isPalindrome(String s) {
        StringBuilder sb=new StringBuilder();

        for(int i=0;i<s.length();i++){
            char ch=filter(s.charAt(i));
            if(ch!=' '){
                sb.append(Character.toString(ch));
            }
        }

        String str=sb.toString();

        int start=0;
        int end=str.length()-1;

        while(start<end){
            if(str.charAt(start)!=str.charAt(end)){
                return false;
            }
            start++;
            end--;
        }

        return true;
    }
}

```
