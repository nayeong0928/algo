# Length of Last Word

## 해석

- 마지막 단어의 글자수를 리턴
- 1 <= s.length <= 10^4
- s는 영어 단어와 ' '로만 이루어져 있음

## 풀이

- 인덱스 i를 s 맨 마지막에서부터 시작해서 공백인 동안 빼준다
- 공백이 아닌 부분을 만나면 cnt로 글자수를 세기 시작한다

```java

class Solution {
    public int lengthOfLastWord(String s) {
        int i=s.length()-1;
        int cnt=0;

        while(i>=0 && s.charAt(i)==' '){
            i--;
        }
        
        while(i>=0 && s.charAt(i)!=' '){
            cnt++;
            i--;
        }

        return cnt;
    }
}

```
