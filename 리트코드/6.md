# Zigzag Conversion

## 분석

- numRows 개의 행에서 지그재그로 문자열을 배치한 다음, 행 순서대로 문자열을 읽는 문제
- 1 <= s.length <= 1000
- 1 <= numRows <= 1000

## 풀이

```java

import java.util.*;

class Solution {
    public String convert(String s, int numRows) {
        LinkedList<String>[] rows=new LinkedList[numRows];
        int now=0;

        for(int k=0;k<numRows;k++){
            rows[k]=new LinkedList<String>();
        }

        while(now<s.length()){

            int i=0;

            while(i<numRows){
                rows[i].add(s.charAt(now)+"");
                now++;
                i++;
                if(now>=s.length()){
                    return output(rows);
                }
            }

            i=numRows-2;

            while(i>0){
                rows[i].add(s.charAt(now)+"");
                now++;
                i--;
                if(now>=s.length()){
                    return output(rows);
                }
            }
        }
        return output(rows);
    }

    private static String output(LinkedList<String>[] rows){
        StringBuilder sb=new StringBuilder();
        
        for(int i=0;i<rows.length;i++){
            for(int j=0;j<rows[i].size();j++){
                sb.append(rows[i].get(j));
            }
        }

        return sb.toString();
    }
}

```
