# 13. Roman to Integer

## 분석

- Roman 수
  |Symbol|Value|
  |---|---|
  |I|1|
  |V    |         5|
  |X    |         10|
  |L    |         50|
  |C    |         100|
  |D    |         500|
  |M    |         1000|

- Roman 수는 오름차순으로 온다
- 작은 수가 큰 수 앞에 있을 때에는 큰 수 - 작은 수 일 경우이다

## 풀이 

- Roman 수는 내림차순이기 때문에, 스택에 전부 값을 넣어놓고 stack.peek()가 스택에서 방금 pop()한 값보다 작으면 빼주도록 했다.

```java

class Solution {
    public int romanToInt(String s) {
        Stack<Integer> stack=new Stack<>();
        
        for(int i=0;i<s.length();i++){
            stack.push(roman(s.charAt(i)));
        }

        int ans=0;

        while(!stack.isEmpty()){
            int p=stack.pop();
            if(!stack.isEmpty() && p>stack.peek()){
                ans+=(p-stack.pop());        
            }
            else {
                ans+=p;
            }
        }

        return ans;
    }

    private static int roman(char ch){
        if(ch=='I'){
            return 1;
        }
        if(ch=='V'){
            return 5;
        }
        if(ch=='X'){
            return 10;
        }
        if(ch=='L'){
            return 50;
        }
        if(ch=='C'){
            return 100;
        }
        if(ch=='D'){
            return 500;
        }
        if(ch=='M'){
            return 1000;
        }
        return -1;
    }
}

```
