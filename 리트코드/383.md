# Ransom Note

## 분석

- ransomNote는 magazine에 있는 글자만 사용해야 한다. 아닐 경우 false를 반환한다.

## 풀이

- magazine에 있는 글자들을 hash에 넣어 각 글자가 몇 개씩 있는지 세어준다.
- ransomNote에서 hash에 없는 글자를 사용한 경우 false를 리턴해준다.
- ransomNote에서 hash에 있는 글자를 사용한 경우, 글자 횟수를 1 줄여준다.

```java

class Solution {
    public boolean canConstruct(String ransomNote, String magazine) {
        HashMap<Character, Integer> hash=new HashMap<Character, Integer>();
        
        for(int i=0;i<magazine.length();i++){
            char ch=magazine.charAt(i);
            hash.put(ch, hash.getOrDefault(ch, 0)+1);
        }

        for(int i=0;i<ransomNote.length();i++){
            char ch=ransomNote.charAt(i);
            if(hash.get(ch)==null || hash.get(ch)<=0){
                return false;
            }
            hash.put(ch, hash.get(ch)-1);
        }

        return true;
    }
}

```
