# Happy Number

## 분석

- 주어진 숫자 n이 happy number인지 여부를 리턴한다.
- happy number: 숫자의 각 자릿수를 제곱해서 더하는 과정을 반복했을 때, 1이 되는 수. 1을 포함하지 않는 사이클을 도는 경우는 happy number가 아니다.
- 1 <= n <= 2^31 - 1

## 풀이

- HashSet: n이 사이클을 도는 경우를 체크하기 위해서 추가했다. 1이 포함되지 않고 예전에 나왔던 수가 반복해서 나오면 happy number가 아니므로 연산을 반복할 필요가 없다.
- calculate(n): n의 각 자릿수를 제곱해서 더한 값을 확인하기 위한 함수이다.

```java

class Solution {
    public boolean isHappy(int n) {
        Set<Integer> set=new HashSet<>();
        
        while(n!=1 && !set.contains(n)){
            set.add(n);
            int sum=calculate(n);
            n=sum;
        }

        if(n==1){
            return true;
        }

        return false;
    }

    private int calculate(int n){
        int sum=0;
        
        while(n>0){
            int r=n%10;
            n=n/10;
            sum+=(r*r);
        }

        return sum;
    }
}
```
