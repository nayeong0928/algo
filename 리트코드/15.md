# 3Sum

## 분석

- 3개의 수를 더했을 때 0이 되는 조합을 찾아서 리턴하기.
- 중복된 경우는 허용하지 않는다.

## 풀이

- nums 배열을 오름차순으로 정렬해준다.
- 가장 오른쪽에 있는 기준값 nums[i]를 기준으로 가장 왼쪽에 있는 nums[left]와 기준값 다음으로 가장 오른쪽에 있는 nums[right] 값과의 합을 구한다. 이 때, 중복 방지를 위해서 기준값이 이미 확인한 값일 경우 진행하지 않고 넘어간다.
- 합이 0보다 큰 경우, right--
- 합이 0보다 작은 경우, left++
- 합이 0과 같은 경우, 리스트에 추가해준다. 이 때, 중복 방지를 위해서 왼쪽/오른쪽에 연속으로 같은 값이 나올 경우 그만큼 더 이동시켜준다.

```java

class Solution {
    public List<List<Integer>> threeSum(int[] nums) {

        List<List<Integer>> list=new ArrayList<>();
        Arrays.sort(nums);

        for(int i=nums.length-1;i>=2;i--){
            
            if(i<nums.length-1 && nums[i]==nums[i+1]) continue;
            
            int left=0;
            int right=i-1;
            
            while(left<right){
                int sum=nums[left]+nums[right]+nums[i];

                if(sum==0){
                    list.add(new ArrayList<>(Arrays.asList(nums[i], nums[left], nums[right])));                    
                    while(right-1>=0 && nums[right]==nums[right-1]) right--;
                    while(left+1<nums.length-1 && nums[left]==nums[left+1]) left++;
                }
                
                if(sum>0){
                    right--;                   
                }
                else {
                    left++;
                }
            }
        }

        return list; 
    }

}

```
