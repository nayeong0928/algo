# Two Sum

## 분석

- nums에서 두 수를 합하면 target이 되는 두 수의 인덱스를 리턴한다.
- nums의 값이 중복되지 않는다는 조건이 없으므로, nums에 똑같은 값이 연속으로 올 경우도 고려해야 한다.

## 풀이

- 브루트 포스 방식으로 두 수를 더하는 모든 경우를 체크하는 방식이 있다.
- 시간복잡도를 줄이기 위해서 수의 합에 따라 위치를 조정하는 슬라이딩 윈도우 방식을 사용한다.
- 슬라이딩 윈도우 방식을 사용하기 위해 nums 배열을 정렬하면, 원래의 인덱스 정보가 사라지기 때문에 HashMap에 nums의 값과 원래 인덱스 값을 저장한다. 이 때 같은 값이 여러번 나올 경우를 대비하여 인덱스 값은 Queue로 저장하여 같은 값의 인덱스값 여러개를 저장한다.
- nums[left]+nums[right]가 target보다 큰 경우: right--
- nums[left]+nums[right]가 target보다 작은 경우: left++
- nums[left]+nums[right]가 target과 같은 경우: while문을 break
- while 문에서 빠져나온 후 HashMap 값에 매핑되는 Queue에서 값을 하나씩 꺼내 리턴한다.

```java

class Solution {
    public int[] twoSum(int[] nums, int target) {
        HashMap<Integer, Queue> map=new HashMap<>();
        
        for(int i=0;i<nums.length;i++){
            if(map.get(nums[i])==null){
                map.put(nums[i], new LinkedList<Integer>());
            }
            map.get(nums[i]).add(i);
        }

        Arrays.sort(nums);

        int left=0;
        int right=nums.length-1;

        while(left<right){
            int sum=nums[left]+nums[right];

            if(sum<target){
                left++;
            }
            else if(sum>target){
                right--;
            }
            else {
                break;
            }
        }

        int[] ans=new int[2];

        ans[0]=(int) map.get(nums[left]).poll();
        ans[1]=(int) map.get(nums[right]).poll();

        return ans;
    }
}

```
